        No disponible (no inventado)

        • Gasto GPU en tiempo real: no disponible — no existe endpoint ni libro de gasto (usage_ledger) en la API actual. En el camino 0 $ no hay GPU: el cómputo es CPU del host. Pendiente: registrar GPU-segundos por trabajo si algún día se usa GPU.
        • Horas procesadas / consumo de API por día: no disponible — la API no expone contadores de YouTube/Twitch/Groq. El panel muestra los límites, no un consumo inventado.
        • Gasto mensual en USD: 0 $ real en el camino 0 $ (host Oracle Always Free + R2 dentro de 10 GB + faster-whisper en CPU). No hay factura que consultar: no existe integración verificada de facturación de ningún proveedor (PRESUPUESTO §5).
